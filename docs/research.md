# Research index

Read [upstream audit](upstream-audit.md) for source-backed foundation selection and
licenses, [Chinese/community research](chinese-project-research.md) for attempted
searches and access failures, and [SM8450 compatibility](sm8450-compatibility.md)
for official and community hardware sources. Machine-readable Git revisions and
search results are under `evidence/research/`.

Evidence labels: HARDWARE_VERIFIED means independently reproduced on the named
physical device; BUILD_VERIFIED means the stated artifact was built; SOURCE_IMPLEMENTED
means inspected non-placeholder source exists; EXPERIMENTAL indicates incomplete
research; UNVERIFIED indicates unsupported claims/access limitations; INCOMPATIBLE
is scoped to a particular SoC, board, license or preservation requirement. These
labels must not be generalized from one module to a whole operating system.

Source access succeeded for the 11 user-listed GitHub projects and DarwinBoot.
The mainline SM8450 DTS and official Xiaomi zeus source-branch Makefile were also
retrieved. Further search discovered three additional SM8450/cupid repositories;
their source and available shallow history were subsequently audited (15 GitHub
repositories total). This session is a bounded source audit,
not an exhaustive claim about all English/Chinese development communities.
